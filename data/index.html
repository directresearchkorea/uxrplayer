Model Comparison
Qwen · Gemma 로컬 LLM 비교 분석 도입
LLM COMPARE SENTIMENT CATEGORY

기존 형태소 분석(키워드 매칭 + KoELECTRA) 방식의 한계를 보완하기 위해, 로컬 Ollama 기반의 Gemma 2 2B(gemma2:2b)와 Qwen 모델을 활용한 LLM 기반 분류 파이프라인을 구축하고 비교 분석을 수행하였습니다.

두 모델 모두 http://localhost:11434/api/generate (Ollama API)를 통해 호출되며, 문장 단위로 구조화된 JSON 프롬프트({"category": "...", "sentiment": "..."})를 전송하여 카테고리와 감정을 동시에 반환받는 구조입니다.

KEY FINDINGS

Gemma 2 2B는 경량 모델로서 초당 처리량이 높아 대량 데이터 파이프라인의 1차 분류기로 적합합니다. 특히 갓겜, 망겜, 꿀잼 등 강한 게이머 은어가 포함된 문장에서의 감정 판별 정확도가 높습니다.

Qwen은 한국어 맥락 이해력과 긴 문장 처리에서 안정적이며, 특히 비꼬기·반어법이 포함된 복합 감정 문장(예: "최적화가 너무 잘 돼서 프레임이 10이 나와요 ^^")의 NEGATIVE 판별에서 Gemma 대비 우위를 보입니다.

현재 운영 환경에서는 Gemma 2 2B를 메인 분류 엔진으로, Qwen을 페르소나 챗봇 + 검증용 보조 엔진으로 이원화 운영 중입니다.

Morphological NLP
파이썬 형태소 분석 기반 카테고리 · 감정 분류 체계 구축
NLP SENTIMENT CATEGORY

붉은사막 커뮤니티 데이터(인벤, 루리웹 등)에 대해 파이썬 기반 형태소 분석을 수행하여 카테고리 및 감정 분류 체계를 확립하였습니다. 사전 기반의 전통적 형태소 분석기(KoNLPy/Mecab) 대신, 게임 커뮤니티 특화 비지도 학습 방식인 soynlp를 핵심 NLP 도구로 채택하였습니다.

soynlp의 LRNounExtractor와 MaxScoreTokenizer를 활용하여 크롤링된 원시 데이터(제목, 본문, 댓글)로부터 동적으로 명사를 추출하고 토크나이저를 학습시키는 구조입니다. 문장 분리에는 KSS(Korean Sentence Splitter)를 사용하여 다문장 게시물을 문장 단위로 분할한 뒤, 각 문장에 대해 Aspect 키워드 매칭 및 감정 판별을 수행합니다.

SENTIMENT ANALYSIS ENGINE (3-TIER)

Tier 1 — 강한 도메인 키워드 오버라이드

강긍정: 갓겜 명작 꿀잼 강추 대만족 인생겜 존잼 → POSITIVE (Confidence 1.0)
강부정: 망겜 똥겜 노잼 쓰레기 최악 환불 비추 접는다 → NEGATIVE (Confidence 1.0)

Tier 2 — Deep Learning (KoELECTRA)

HuggingFace koelectra-base-v3-generalized-sentiment-analysis 모델을 사용한 문맥 기반 감정 분류. Confidence 0.75 미만 시 NEUTRAL로 폴백.

Tier 3 — Lexicon Fallback

오프라인 환경이거나 모델 로드 실패 시, 긍정/부정 사전 단어 카운트 기반 판별.
