1. 페르소나 챗봇 답변 프로세스 (Persona Chatbot Answering Process)

유저 클러스터링 기반 페르소나 프로필과 원문 피드백 데이터를 활용하여, 기획자(PM)의 질문에 실제 해당 성향의 유저인 것처럼 1인칭 시점(구어체 존댓말)으로 답변하는 RAG(Retrieval-Augmented Generation) 시스템을 가동합니다.

  • SQLite 기반 실시간 RAG: 기획자가 입력한 질문에서 형태소 및 불용어를 정제한 뒤, 해당 유저 클러스터(페르소나)의 원문 피드백 데이터베이스(analyzed_aspects)에서 키워드 및 의미적 연관성이 높은 구절들을 실시간으로 로드합니다. (로컬 임베딩 모델 snunlp/KR-SBERT-V4 cosine similarity 매칭 작동)
  • 2단계 교차 인코더 재정렬 (Cross-Encoder Reranking): 1차로 필터링된 후보 유저 피드백들을 정밀 문맥 인식 모델인 교차 인코더(bongsoo/klue-cross-encoder-v1)로 재평정하여, 연관도 점수가 가장 높은 상위 4개(로컬 Ollama 구동 시 하드웨어 부하 조절을 위해 3개)의 Verbatim을 최종 답변 생성의 Context(근거 자료)로 확정합니다.
  • 페르소나 역할극 합성 (Prompt Synthesis): 최종 선정된 Verbatim들과 함께 해당 페르소나의 인구통계학적 특성/핵심 불만사항, 그리고 엄격한 구어체 1인칭 답변 지침(해요체 존댓말 사용, 제3자 시점 요약 금지, 볼드체/마크다운 기호 사용 배제)을 결합하여 컨텍스트 프롬프트를 빌드합니다.
  • LLM 추론 및 폴백 (Generation & Fallback): 온라인 환경에서는 Gemini 2.5 Flash API를 활용해 고품질 답변을 도출하며, 오프라인 환경이나 API 한계 시 로컬 Ollama API의 gemma2:2b 또는 qwen 엔진으로 전환합니다. 양쪽 모두 호출 불가능할 경우, 클러스터 성향에 맞춰 사전 정의된 규칙 기반 Mock 응답으로 매끄럽게 폴백됩니다.

2. 대표 Verbatim 선정 프로세스 (Representative Verbatim Selection Process)

대시보드 및 페르소나 분석에 활용되는 실제 유저 원어 반응(Verbatim) 데이터를 객관적이고 신뢰도 높은 순서로 선별하여 가독성과 품질을 향상하기 위한 자동 필터링 파이프라인입니다.

  • 데이터베이스 레벨 1차 필터링: 감성 분석 결과가 명확한 문장(POSITIVE 또는 NEGATIVE)만 대상으로 삼으며, 잡담성 중립 글(NEUTRAL)은 수집하지 않습니다. 또한, 충분한 정보와 묘사를 담고 있도록 글자 수 40자 이상(LENGTH(matched_text) >= 40) 및 모델 판별 신뢰도 75% 이상(confidence_score >= 0.75)의 구절만 DB 상에서 필터링합니다.
  • 신뢰도 및 품질 정렬: 추출 대상 문장들을 ORDER BY confidence_score DESC, LENGTH(matched_text) DESC 기준으로 정렬합니다. 이를 통해 AI 모델이 가장 높은 신뢰도를 주었으면서 풍부한 구체적 설명을 곁들인 유저의 피드백이 항상 최상단에 대표적으로 노출되도록 보장합니다.
  • 노이즈 및 스팸 정규식 클리닝: 정렬 후 루프 분석 단계에서, 특정 한글 초성/모음이 5회 이상 연속으로 나열되어 글의 가치를 저해하는 노이즈 텍스트(예: ㅋㅋㅋㅋㅋ, ㅎㅎㅎㅎㅎ, ㅠㅠㅠㅠㅠ 등)가 감지될 경우 수집 필터에서 자동으로 제외(bypass)합니다.
  • 중복 배제 및 용량 최적화: 날짜, 카테고리, 감성 축별로 동일 문장의 중복 적재를 막는 중복성 검사(deduplication)를 적용하며, 최종 데이터 파일 크기를 경량화하여 프론트엔드 렌더링 성능을 지키기 위해 **날짜-카테고리-감성별 최대 3개**의 고유 Verbatim만 정제하여 최종 아카이빙합니다.

3. Qwen · Gemma 로컬 LLM 비교 분석 도입

기존 형태소 분석(키워드 매칭 + KoELECTRA) 방식의 한계를 보완하기 위해, 로컬 Ollama 기반의 Gemma 2 2B(gemma2:2b)와 Qwen 모델을 활용한 LLM 기반 분류 파이프라인을 구축하고 비교 분석을 수행하였습니다.

두 모델 모두 http://localhost:11434/api/generate (Ollama API)를 통해 호출되며, 문장 단위로 구조화된 JSON 프롬프트({"category": "...", "sentiment": "..."})를 전송하여 카테고리와 감정을 동시에 반환받는 구조입니다.

KEY FINDINGS

Gemma 2 2B는 경량 모델로서 초당 처리량이 높아 대량 데이터 파이프라인의 1차 분류기로 적합합니다. 특히 갓겜, 망겜, 꿀잼 등 강한 게이머 은어가 포함된 문장에서의 감정 판별 정확도가 높습니다.

Qwen은 한국어 맥락 이해력과 긴 문장 처리에서 안정적이며, 특히 비꼬기·반어법이 포함된 복합 감정 문장(예: "최적화가 너무 잘 돼서 프레임이 10이 나와요 ^^")의 NEGATIVE 판별에서 Gemma 대비 우위를 보입니다.

현재 운영 환경에서는 Gemma 2 2B를 메인 분류 엔진으로, Qwen을 페르소나 챗봇 + 검증용 보조 엔진으로 이원화 운영 중입니다.

NLP SENTIMENT CATEGORY

붉은사막 커뮤니티 데이터(인벤, 루리웹 등)에 대해 파이썬 기반 형태소 분석을 수행하여 카테고리 및 감정 분류 체계를 확립하였습니다. 사전 기반의 전통적 형태소 분석기(KoNLPy/Mecab) 대신, 게임 커뮤니티 특화 비지도 학습 방식인 soynlp를 핵심 NLP 도구로 채택하였습니다.

soynlp의 LRNounExtractor와 MaxScoreTokenizer를 활용하여 크롤링된 원시 데이터(제목, 본문, 댓글)로부터 동적으로 명사를 추출하고 토크나이저를 학습시키는 구조입니다. 문장 분리에는 KSS(Korean Sentence Splitter)를 사용하여 다문장 게시물을 문장 단위로 분할한 뒤, 각 문장에 대해 Aspect 키워드 매칭 및 감정 판별을 수행합니다.

SENTIMENT ANALYSIS ENGINE (3-TIER)

Tier 1 — 강한 도메인 키워드 오버라이드

강긍정: 갓겜 명작 꿀잼 강추 대만족 인생겜 존잼 → POSITIVE (Confidence 1.0)
강부정: 망겜 똥겜 노잼 쓰레기 최악 환불 비추 접는다 → NEGATIVE (Confidence 1.0)

Tier 2 — Deep Learning (KoELECTRA)

HuggingFace koelectra-base-v3-generalized-sentiment-analysis 모델을 사용한 문맥 기반 감정 분류. Confidence 0.75 미만 시 NEUTRAL로 폴백.

Tier 3 — Lexicon Fallback

오프라인 환경이거나 모델 로드 실패 시, 긍정/부정 사전 단어 카운트 기반 판별.
