COMMUNITY ANALYSIS

Web community analysis and AI persona chat dashboard. Track community traffic trends, user behavior, and major updates timelines for deeper player insights.

1. At a Glance: Public Opinion Flow (Traffic & Sentiment Trends)

Displays the time-series trends of user community activity (Traffic) and positive/negative sentiment. Through intuitive graphs, you can see how user reactions have changed after specific updates or events. By breaking down the Aspect-Based Sentiment (e.g., graphics, gameplay, optimization), it accurately pinpoints areas receiving praise and areas causing dissatisfaction.

2. Who Leaves and Who Stays? (User Churn Risk Matrix & Flow)

One of the core features of this dashboard is preventing user churn.

  • Risk Matrix: Clusters user activity and sentiment indices into 4 groups (Casual Socializers, Loyal Power Users, Active Critics, Inactive & High Churn Risks) using the K-Means algorithm. You can pinpoint exactly which users are at a high risk of churning.
  • Sentiment Shift Flow (Sankey Diagram): Visualizes how initial user sentiment changes over time and their final state (Active vs. Inactive), providing clear directions for user retention management.

3. Converse with Living Data (AI Persona Chat)

This is the most innovative feature of the dashboard! Beyond simply looking at numbers, an AI (Gemini / Ollama) takes on the persona of clustered user segments based on actual data to function as a chatbot. For instance, if you ask, "What do core gamers think about the recent optimization issues?", the AI—trained on real data from that specific user group—will answer with vivid feedback, complaints, and areas for improvement directly from the user's perspective.
